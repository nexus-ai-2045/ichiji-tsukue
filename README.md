# light-fact-search

軽い一次情報検索

公式発表、論文、Git の Release だけを一次にする調査ツール。（旧称: 一次机）

公開リポジトリだが、中に置くのは仕様だけ。鍵、セッション、クエリログ、ページ本文は入れない。

入場の予定は、[@ya_sup](https://x.com/ya_sup) または [@nexus_ai_2045](https://x.com/nexus_ai_2045) のフォロー、note のフォロー、自分が立てた Discord でロールを持っている人。どれか一本。フォロー確認はまだ繋いでいない。繋ぐまで外に出さない。

引く先は OpenAlex、GitHub、Hacker News。公式の URL と日付に着地しないものは事実にしない。
